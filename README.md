# Amazon Clone
A simple front-end clone of the Amazon homepage built using **HTML** and **CSS**. This project is a static website that replicates the design and layout of Amazon to practice front-end web development skills.

## 🔧 Features

* Responsive navigation bar
* Search bar UI
* Product sections with images
* Footer with links (like the original Amazon site)
* Clean layout using CSS Flexbox/Grid

## 🚀 Technologies Used

* HTML5
* CSS3

## 📁 Project Structure

```
/amazon-clone
│
├── index.html
├── style.css
└── /images
```
